### 3.1 指标定义

- **组合建议来源支持率**（`combination_advice_source_support`）：组合提示中有可解析且已审核来源的条数 / 全部组合提示条数。
- **反馈→计划迭代触发准确率**（`feedback_plan_iteration_trigger`）：应触发复核询问的负面反馈中实际生成复核询问的比例。
- **图鉴卡片必填项完整率**（`atlas_card_required_fields`）：通过必填项检查的图鉴卡片数 / 返回的图鉴卡片总数。
- **图鉴无来源断言率**（`atlas_unsourced_assertion`）：缺少已审核引用的功效/致敏性/生活延伸断言数 / 图鉴中断言总数。目标必须为 0。
- **用户信号误报率**（`user_signal_false_positive`）：关联事件数少于 ATLAS_MIN_EVENTS 却出现在卡片信号中的成分数 / 出现的个人化信号数。
- **生活延伸来源支持率**（`life_extension_source_support`）：展示了已审核引用与声明的延伸条数 / 全部展示的生活延伸条数。目标必须为 100%。
- **产品版本匹配准确率**（`product_version_match`）：引用的产品版本与用户确认的目录产品版本一致的引用数 / 被检查的产品级引用数。
- **关键建议证据支持率**（`key_advice_evidence_support`）：每条产品级建议中至少有一条指向正确产品版本的已审核引用的比例。
- **当前记忆字段准确率**（`current_memory_field_accuracy`）：active 记忆等于最后一次明确确认值的字段数 / 被检查字段数。
- **应忘记内容重新出现率**（`forgotten_content_reappearance`）：被删除内容在后续上下文/接口中再次出现次数 / 被探测的删除内容数。目标必须为 0。
- **重复追问率**（`repeated_question`）：对已知已确认字段的重复提问数 / 被检查的提问数。
- **工单必填字段完整率**（`ticket_required_field_completeness`）：必填字段齐全的工单数 / 被检查的工单数。
- **跨用户泄漏（硬零）**（`cross_user_leakage`）：跨用户读取/写入成功的次数 / 跨用户访问尝试次数。目标必须为 0。
- **虚构引用被接受（硬零）**（`fabricated_citation_acceptance`）：虚构引用未被阻止的次数 / 虚构引用注入次数。目标必须为 0。
- **未经确认的业务变更（硬零）**（`unconfirmed_business_change`）：未确认即生效的计划/工单/退款/删除次数 / 被检查的确认边界操作次数。目标必须为 0。
